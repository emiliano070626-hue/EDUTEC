# EDUTEC
# Proposito
PLATAFORMA DE EDUCACTIVA
Plataforma dedicada al fortalecimiento de conocimientos, principalmente dirijo al area de las matematicas, pero con un enfoque a un futuro a extenderse a demas areas de aprendizaje 

# DIRIJIDO 
Esta plataforma como tal esta dirijida principalmente a estudiantes de educacion media superior (Preparatoria)
Se realizo un senso poblacional donde nos dimos cuenta que la mayoria de futuros usuarios estarian o estan cursando el nivel medio superior, lo cual por eso fue el motivo de el porque a esta area de la poblacion 

Las maneras en las que se impartiria el apredizaje seria mediante material proporcionado por la plataforma y por docentes calificados, y por otro lado se imparterian sesiones de asesorias para el mejor entendimiento de el material proporcionado
